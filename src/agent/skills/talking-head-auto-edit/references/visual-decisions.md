# 视觉决策规则——触发类型对应效果与生成规则

每种触发类型对应一套具体的效果生成和放置方案。

---

## 1. 开场钩子 → 标题大字揭示

**什么时候用**：视频开头 0–10 秒，讲话引入核心主题时

**效果形式**：1–3 个关键词从中央或左侧扫光揭示，3 秒，覆盖在演讲者画面上方

**submit_motion_graphic prompt 写法**：
```
大字动效：从左向右扫光揭示关键词"[从讲话里提取的1-3个词]"，
白色粗体大字，深色半透明背景条，现代简洁风格，3秒，
字体大小约画布高度的 20%，放置在画面上方 1/4 区域
```

**放置**：`edit_item` adds，type=motion-graphic，track=V2，fromFrame=触发帧

---

## 2. 数字/统计 → 数字强调卡片

**什么时候用**：讲话中出现具体数字、百分比、金额

**效果形式**：数字居中放大突出，标签文字说明，有计数动画，3–4 秒

**prompt 写法**：
```
数字强调卡片：中央大数字"[实际数字，如 400%]"，
下方标签"[数字的含义，如 三个月增长]"，
深色卡片背景，数字有从 0 计数到目标值的动画，
金色/白色强调色，现代商务风，4秒
```

**放置**：演讲者在画面中央时 → 卡片放右侧 1/3 区域（`transform.x` ≈ 0.25）；演讲者偏左时 → 放右侧

---

## 3. 列表/步骤 → 序号条逐一显示

**什么时候用**：讲到"第一"/"第二"/"首先"/"然后"等结构化内容

**效果形式**：每一项一个 MG，随讲话依次出现；或者一次性显示全部列表，配合讲话节奏逐项高亮

**每项的 prompt 写法**：
```
列表条 MG：左侧数字序号"[N]"，右侧文字"[该项核心词，≤8字]"，
从左向右滑入，圆角深色条状设计，序号有填充动画，
与其他同系列条保持视觉一致（同色系/同字体），3秒
```

**注意**：同一个视频里所有列表条应用相同的配色方案，在第一条生成后把配色参数记下来，后续条复用。

**放置**：全部放 V2 轨道，按各自的 fromFrame 依次放置，不要互相叠加

---

## 4. 对比 → 分栏对比卡

**什么时候用**：讲话里有明显的"旧vs新"、"方法A vs 方法B"、"以前vs现在"

**效果形式**：左右两栏，各有标题和 1–2 行描述，有差异色高亮，5–6 秒

**prompt 写法**：
```
对比卡片：左栏标题"[旧/方法A/以前的说法]"配描述"[1-2个词]"，
右栏标题"[新/方法B/现在的说法]"配描述"[1-2个词]"，
左栏暗色调，右栏亮色/强调色，中间有分隔线，
从两侧向中心滑入，5秒
```

**放置**：对比卡占画面较大比例，检查是否遮挡演讲者——如果遮挡则缩小到右侧 50% 区域

---

## 5. 具体事物/场景 → 配图（Unsplash 或 GPT 生图）

**什么时候用**：讲话提到具体的产品、地点、工具、概念

**决策逻辑**：
- 真实照片类（城市、产品、人物、自然）→ `search_photos`（Unsplash）
- 需要定制化图（UI 截图、示意图、品牌图、图表）→ `submit_image`（GPT 生图）

**search_photos 关键词原则**：
- 直接用讲话里提到的名词，不要泛化
- 讲"北京的写字楼" → 搜 "Beijing office building"
- 讲"AI 算法" → 搜 "neural network visualization" 或 "data science"

**submit_image prompt 写法**：
```
[描述内容]，干净的背景，适合作为视频配图，
16:9 比例，高清，商业插画风格 / 照片写实风格
```

**放置方式（PiP）**：
- 图片作为 B-roll 配图，放 V1 替换掉该片段；或
- 以画中画形式放在演讲者右侧，`transform.scale=0.45`，`transform.x=0.27`（右侧居中）

---

## 6. 问题/悬念 → 问题卡片或文字浮现

**什么时候用**：演讲者抛出一个问题，希望引发观众思考

**效果形式**：问题文字从中央渐显，配有大问号装饰，2–3 秒后淡出

**prompt 写法**：
```
问题文字卡片：中央显示"[讲话里的问题句，≤15字]"，
大号问号装饰在文字旁边，白色文字，渐显渐出，
简洁干净，不抢主视觉，3秒
```

---

## 7. 演示/截图 → 全屏切出 + 演讲者圆形 PiP

**什么时候用**：演讲者说"你可以看到"、"这个页面"，且有屏录/截图素材

**操作步骤**：
1. 把屏录片段放 V1（替换演讲者画面）
2. 演讲者视频用 `edit_item` 缩小并加圆角，变成 PiP：
   ```
   transform: { scale: 0.28, x: -0.35, y: 0.35, borderRadius: "50%" }
   ```
   放置在左下角（或右下角，取决于屏录内容的重点区域）
3. 如果没有屏录素材，用 `submit_image` 生成示意截图配图

---

## 8. 章节过渡 → 章节标题卡（可选）

**什么时候用**：视频 > 3 分钟，有明显的章节切换

**效果形式**：全屏或半屏出现章节标题，1.5–2 秒，用于给观众定位

**prompt 写法**：
```
章节标题卡：中央大字"[章节名]"，简洁的进场动画（从下方滑入），
深色背景，字体现代，2秒，结尾淡出
```

---

## 9. CTA → 行动号召卡

**什么时候用**：视频结尾，演讲者提到关注、点赞、订阅

**效果形式**：3–4 个圆形/方形按钮排成一行，有图标，4 秒

**prompt 写法**：
```
片尾 CTA 按钮组：三个圆形图标按钮从左到右依次弹出，
分别是"点赞"、"关注"、"评论"，图标搭配文字标签，
现代设计感，有弹出动画，4秒，放置在画面下方
```

---

## 放置检查清单（每个效果放置后确认）

- [ ] 截帧确认没有遮挡演讲者的脸
- [ ] 没有盖住手部（演讲者手势区域）
- [ ] 字幕区域（画面底部 15%）保持清晰
- [ ] fromFrame 对应的是讲话开始的帧，不是上一句结尾
- [ ] 效果持续时间不超过对应讲话片段的时长（不要"残留"到下一个话题）

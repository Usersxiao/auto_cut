# 视觉决策规则——触发类型对应效果与生成规则

每种触发类型对应一套具体的效果生成和放置方案。

---

## 1. 开场钩子 → 标题大字揭示

**什么时候用**：视频开头 0–10 秒，讲话引入核心主题时

**效果形式**：1–3 个关键词从中央或左侧扫光揭示，3 秒，覆盖在演讲者画面上方

**submit_motion_graphic prompt 写法**：
```
大字动效：从左向右扫光揭示关键词"[从讲话里提取的1-3个词]"，
白色粗体大字，深色半透明背景条，现代简洁风格，3秒，
字体大小约画布高度的 20%，放置在画面上方 1/4 区域
```

**放置**：`edit_item` adds，type=motion-graphic，track=V2，fromFrame=触发帧

---

## 2. 数字/统计 → 数字强调卡片

**什么时候用**：讲话中出现具体数字、百分比、金额

**效果形式**：数字居中放大突出，标签文字说明，有计数动画，3–4 秒

**prompt 写法**：
```
数字强调卡片：中央大数字"[实际数字，如 400%]"，
下方标签"[数字的含义，如 三个月增长]"，
深色卡片背景，数字有从 0 计数到目标值的动画，
金色/白色强调色，现代商务风，4秒
```

**放置**：演讲者在画面中央时 → 卡片放右侧 1/3 区域（`transform.x` ≈ 0.25）；演讲者偏左时 → 放右侧

---

## 3. 列表/步骤 → 序号条逐一显示

**什么时候用**：讲到"第一"/"第二"/"首先"/"然后"等结构化内容

**效果形式**：每一项一个 MG，随讲话依次出现；或者一次性显示全部列表，配合讲话节奏逐项高亮

**每项的 prompt 写法**：
```
列表条 MG：左侧数字序号"[N]"，右侧文字"[该项核心词，≤8字]"，
从左向右滑入，圆角深色条状设计，序号有填充动画，
与其他同系列条保持视觉一致（同色系/同字体），3秒
```

**注意**：同一个视频里所有列表条应用相同的配色方案，在第一条生成后把配色参数记下来，后续条复用。

**放置**：全部放 V2 轨道，按各自的 fromFrame 依次放置，不要互相叠加

---

## 4. 对比 → 分栏对比卡

**什么时候用**：讲话里有明显的"旧vs新"、"方法A vs 方法B"、"以前vs现在"

**效果形式**：左右两栏，各有标题和 1–2 行描述，有差异色高亮，5–6 秒

**prompt 写法**：
```
对比卡片：左栏标题"[旧/方法A/以前的说法]"配描述"[1-2个词]"，
右栏标题"[新/方法B/现在的说法]"配描述"[1-2个词]"，
左栏暗色调，右栏亮色/强调色，中间有分隔线，
从两侧向中心滑入，5秒
```

**放置**：对比卡占画面较大比例，检查是否遮挡演讲者——如果遮挡则缩小到右侧 50% 区域

---

## 5. 配图（Unsplash 或 GPT 生图）——主动触发，不等讲话"明确提到"

**配图是必须完成的任务，不是可选项。** 每段视频至少 3 张配图，且每隔约 8–10 秒就应当有一张出现。

**主动配图时机**（不需要等到讲话明确提及才触发）：
- 讲话中出现任何名词（产品、工具、地方、概念、行业、人物）→ 立即触发
- 已经过了 8 秒没有配图出现 → 主动找一张与当前话题相关的图补上
- 开场 5 秒内 → 必须有一张图建立视觉基调

**决策逻辑**：
- 真实照片类（城市、产品、人物、自然、职场）→ `search_photos`（Unsplash）
- 需要定制化图（示意图、图表、流程图）→ `submit_image`（GPT 生图）

**search_photos 关键词规则**：
- 中文关键词必须翻译成英文才能搜索
- 关键词要具体，不要泛化：讲"职场竞争" → 搜 "business competition" 而非 "work"
- 讲"AI 算法" → 搜 "neural network" 或 "machine learning visualization"
- 讲"创业" → 搜 "startup office" 或 "entrepreneur"

**submit_image prompt 写法**：
```
[描述内容]，简洁干净的背景，适合作为竖屏视频配图，
9:16 比例，高清，现代商业风格
```

## 5. 配图——全屏切出，演讲者完全消失

**核心原则：配图不叠加在演讲者上，而是完全替换主轨道，演讲者在这段时间内消失。**

参考视频里所有"素材图"的做法都是这样：整个画面切到截图/新闻/图片，字幕仍然在底部，但演讲者不见了。

### 做法 A：全屏切出（最常用）

适用于：网页截图、新闻截图、PDF、产品截图、数据图表

```
edit_item adds:
  type: image
  assetId: <从 search_photos 或 submit_image 得到的 assetId>
  track: V1                    ← 放在主轨，不是 V2/V3
  fromFrame: <讲话开始帧>
  durationInFrames: <对应讲话段的帧数>
  transform:
    scale: 1.0                 ← 全屏，不缩小
```

演讲者的原始视频片段在这段时间被图片覆盖（V1 上图片层叠在视频之上，或者先 split_item 再把这段替换成图片）。字幕仍然在底部居中正常显示。

**search_photos 关键词**：中文讲话内容翻译成英文，取最核心的名词：
- 讲"纳斯达克创新高" → 搜 "nasdaq stock market"
- 讲"AI 编程工具" → 搜 "coding AI developer"
- 讲"每周升级" → 搜 "software update technology"

### 做法 B：演讲者圆形 PiP + 屏录主画面

仅用于：演讲者明确展示某个软件/工具的操作界面，且有屏录素材

```
# 1. 把屏录放 V1（主画面）
edit_item adds: { type: video, assetId: <屏录>, track: V1, fromFrame: ... }

# 2. 演讲者原始视频放 V2，缩成圆形 PiP，放左下角
edit_item updates:
  itemId: <演讲者视频 itemId>
  transform:
    scale: 0.28
    x: -0.35      ← 左侧
    y: 0.32       ← 下方（留出底部字幕空间）
    borderRadius: "50%"
```

如果没有屏录素材：不要做这种模式，改用做法 A 放一张截图图片。

### 不要做的事

- ❌ 不要把配图以小卡片形式叠加在演讲者身上
- ❌ 不要让配图和演讲者同时出现在画面里（除非是圆形 PiP 模式）
- ❌ 不要用 transform.scale 把图片缩小到 0.4 然后贴在角落——参考视频没有这种做法

## 6. 问题/悬念 → 问题卡片或文字浮现

**什么时候用**：演讲者抛出一个问题，希望引发观众思考

**效果形式**：问题文字从中央渐显，配有大问号装饰，2–3 秒后淡出

**prompt 写法**：
```
问题文字卡片：中央显示"[讲话里的问题句，≤15字]"，
大号问号装饰在文字旁边，白色文字，渐显渐出，
简洁干净，不抢主视觉，3秒
```

---

## 7. 演示/截图 → 全屏切出 + 演讲者圆形 PiP

**什么时候用**：演讲者说"你可以看到"、"这个页面"，且有屏录/截图素材

**操作步骤**：
1. 把屏录片段放 V1（替换演讲者画面）
2. 演讲者视频用 `edit_item` 缩小并加圆角，变成 PiP：
   ```
   transform: { scale: 0.28, x: -0.35, y: 0.35, borderRadius: "50%" }
   ```
   放置在左下角（或右下角，取决于屏录内容的重点区域）
3. 如果没有屏录素材，用 `submit_image` 生成示意截图配图

---

## 8. 章节过渡 → 章节标题卡（可选）

**什么时候用**：视频 > 3 分钟，有明显的章节切换

**效果形式**：全屏或半屏出现章节标题，1.5–2 秒，用于给观众定位

**prompt 写法**：
```
章节标题卡：中央大字"[章节名]"，简洁的进场动画（从下方滑入），
深色背景，字体现代，2秒，结尾淡出
```

---

## 9. CTA → 行动号召卡

**什么时候用**：视频结尾，演讲者提到关注、点赞、订阅

**效果形式**：3–4 个圆形/方形按钮排成一行，有图标，4 秒

**prompt 写法**：
```
片尾 CTA 按钮组：三个圆形图标按钮从左到右依次弹出，
分别是"点赞"、"关注"、"评论"，图标搭配文字标签，
现代设计感，有弹出动画，4秒，放置在画面下方
```

---

## 放置检查清单（每个效果放置后确认）

- [ ] 截帧确认没有遮挡演讲者的脸
- [ ] 没有盖住手部（演讲者手势区域）
- [ ] 字幕区域（画面底部 15%）保持清晰
- [ ] fromFrame 对应的是讲话开始的帧，不是上一句结尾
- [ ] 效果持续时间不超过对应讲话片段的时长（不要"残留"到下一个话题）

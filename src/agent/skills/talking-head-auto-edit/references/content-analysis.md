# 内容分析规则——从文字稿提取视觉触发点

从转录结果中逐句扫描，识别以下触发类型并记录起止时间。

---

## 触发类型分类表

| 触发类型 | 识别关键词 / 模式 | 优先级 |
|---|---|---|
| **开场钩子** | 开头 0–10 秒；"今天"、"分享"、"聊一聊"、"来说说" | 高 |
| **核心论点** | 语气强烈的判断句；"最重要的是"、"关键是"、"本质上" | 高 |
| **数字 / 统计** | 出现具体数字、百分比、金额、时间跨度 | 高 |
| **列表 / 步骤** | "第一"/"第二"/"第三"；"首先"/"然后"/"最后" | 高 |
| **对比** | "以前"vs"现在"；"旧"vs"新"；"A 还是 B" | 中 |
| **具体事物 / 场景** | 提到具体产品、地方、人物、工具、网站 | 中 |
| **引用 / 数据来源** | "根据某研究"、"xxx 数据显示"、"某报告" | 中 |
| **问题 / 悬念** | 句末问号；"为什么"、"怎么做"、"有没有想过" | 中 |
| **章节过渡** | "接下来"、"下面"、"我们来看第N点" | 低 |
| **CTA / 行动号召** | "关注"、"订阅"、"评论"、"点赞"、"私信" | 低 |
| **演示 / 截图** | "你可以看到"、"这张图"、"页面上" | 视情况 |

---

## 扫描流程

1. 把完整文字稿分成语义段落（不按句子，按完整意思单元）
2. 对每个段落打上触发类型标签（可以有多个）
3. 记录段落起始帧（从文字稿时间戳换算：`秒 × fps`）
4. 过滤掉时长 < 2 秒的片段（太短放不下效果）
5. 在相邻两个触发点之间保持至少 3 秒间距（不然太密）

---

## 优先级决策

当触发点过密时，按以下顺序保留：

1. 数字/统计 > 核心论点 > 开场钩子
2. 列表/步骤（保留每一项，序号条依次出现）
3. 对比（高价值，但每个视频最多 2 次）
4. 具体事物（看有没有好的 Unsplash 图片）
5. 章节过渡、CTA（根据视频长度选择性加）

---

## 效果决策表输出格式

分析完成后，生成一张效果决策表：

```
| 时间点(秒) | 起始帧 | 讲话内容摘要（≤20字） | 触发类型 | 建议效果 | 素材来源 |
|------------|--------|----------------------|---------|---------|---------|
| 3.2        | 96     | "今天分享一个改变我的认知" | 开场钩子 | 大字揭示 | submit_motion_graphic |
| 12.8       | 384    | "三个月增长了400%"    | 数字/统计 | 数字卡片 | submit_motion_graphic |
| 28.0       | 840    | "第一点：专注度"       | 列表项目 | 列表条   | submit_motion_graphic |
| 45.3       | 1359   | "就像这款工具一样"     | 具体事物 | 配图     | search_photos |
```

这张表是后续所有效果生成和放置操作的唯一依据。不要在生成阶段重新分析文字稿。

---

## 注意事项

- 不要对同一段话重复打标签（一个位置只对应一个效果）
- 讲话停顿 > 1 秒的位置通常是效果的自然终止点
- 如果演讲者手势活跃（截帧可见），该段暂不加覆盖型效果
- 开头 15 秒是最重要的留存窗口，即使内容触发点不多也应安排 1–2 个效果
